# 个人仓库管理系统

> 一个跨平台的个人物品管理工具，帮助记录、整理和查询物品信息。

## 项目简介

线上购物频率越来越高，囤积物品后容易忘记已有物品、重复购买、找不到东西。本项目提供一个简洁实用的个人仓库管理方案。

**核心理念**：打开即用、无需登录、数据本地存储、用户完全掌控。

## 技术栈

| 层级 | 技术 |
|------|------|
| 前端框架 | React Native 0.83 + Expo SDK 55 |
| 导航 | expo-router（文件路由） |
| 数据存储 | JSON 文件（expo-file-system） |
| 开发语言 | TypeScript |
| 运行平台 | Web / iOS / Android |

## 快速开始

```bash
cd warehouse-app
npm install
npx expo start --web
```

浏览器访问 `http://localhost:8081` 即可使用。

## 目录结构

```
warehouse-app/
├── app/                    # 路由页面（expo-router 文件路由）
│   ├── _layout.tsx         # 根布局
│   └── (tabs)/             # 底部 Tab 导航
│       ├── items/          # 物品管理（列表、添加、详情、编辑）
│       ├── categories/     # 分类管理
│       ├── search/         # 搜索筛选
│       └── profile/        # 个人设置（数据概览、同步、AI 配置）
├── components/             # 可复用 UI 组件
├── src/
│   ├── types.ts            # 类型定义
│   ├── storage/            # 数据存储层（JSON 读写、同步、图片）
│   ├── repositories/       # 数据仓储层（物品、分类、个人资料）
│   └── ocr/                # OCR 识别与文件导入服务
└── database/               # 数据库参考 DDL（仅文档）
```

## 功能特性

- **物品管理**：添加、编辑、删除物品，支持名称、品牌、价格、购买平台、存放位置等字段
- **分类管理**：自定义分类（emoji 图标 + 颜色标识）
- **搜索筛选**：关键词搜索 + 分类/状态筛选
- **图片管理**：为物品添加多张图片
- **自定义字段**：不同分类可配置额外字段（文本/数字/日期）
- **数据导入**：支持订单截图 AI 识别、CSV/Excel 批量导入
- **数据同步**：手动导出/导入 JSON，支持云盘文件夹多设备同步
- **等级系统**：6 级成长体系，激励持续使用

## 多设备同步

1. 在一台设备上使用 App 管理物品
2. 进入「我的」→ 点击「导出 JSON」
3. 将下载的 `warehouse-data.json` 放入云盘同步文件夹
4. 在另一台设备上进入「我的」→ 点击「导入 JSON」→ 选择同步文件夹中的文件
5. 数据自动按时间戳合并

## 一、项目概述

### 1.1 项目名称

物匣（wuxia）

### 1.1.1 品牌用语

| 用语 | 含义 | 界面用法 |
|------|------|----------|
| **物匣** | 产品本身 / 整匣收藏 | 品牌名、概览、统计 |
| **匣中** | 匣内之物的集合与列表 | 底部 Tab、列表页标题 |
| **匣物** | 单件收录之物 | 表单字段、提醒、空状态 |
| **匣主** | 使用者 / 设置与资料 | 底部 Tab、资料页、等级 |
| **匣灵** | AI 助手 | 问答页、评价入口 |
| **入匣 / 改匣** | 新增 / 编辑匣物 | 页面标题与操作按钮 |

### 1.2 项目背景

线上购物频率越来越高，很多人囤积大量东西后出现：忘记匣中已有之物、重复购买、找不到东西、无法统计消费、闲置浪费等问题。

市面上普通记事/清单类应用缺少对个人收藏的系统化管理。

本项目构建一个**个人物匣**，帮助匣主记录、整理和寻觅匣中之物。v3 版本在 v2 的"简洁实用"基础上，补齐了图片管理、数据导入、匣灵问答、统计分析、闲置提醒、匣主等级等完整闭环功能。

### 1.3 当前版本

**v3.0.0** — 全功能版本：图片管理 + 自定义字段 + 匣灵问答 + 批量导入 + 物匣统计 + 闲置提醒 + 匣主等级

| 版本 | 日期 | 关键变化 |
|------|------|----------|

| v2.0 | 2026-05-21 | 去登录化 + JSON 本地存储 + 云盘同步 + OCR/CSV 导入 + 等级系统 |

## 二、项目定位

手机 App 个人物匣，基于 **React Native + Expo**，通过 EAS 构建并部署到手机端。

- **部署形态**：原生手机 App（Android 为主，iOS 可构建）；**不包含 Web / 浏览器端**
- 以「物匣」为核心品牌；匣中收录匣物，匣主打理，匣灵应答
- 打开即用，无需注册登录
- 数据 JSON 本地存储，匣主完全掌控
- 支持云盘文件夹同步，实现多设备数据流转
- 内置 AI 能力：截图识别订单 + 匣灵自然语言问答

## 七、功能需求说明

### 7.1 匣中管理模块

**功能描述**：入匣、改匣、移出与查看匣物信息，支持图片和自定义字段。

**基础字段**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 匣物名称 | 文本 | ✅ | — |
| 分类 | 分类引用 | ❌ | 关联分类表，切换分类时自定义字段值会重置 |
| 品牌 | 文本 | ❌ | 如 Apple |
| 购买时间 | 日期 | ❌ | YYYY-MM-DD，通过 DatePickerModal 选择 |
| 购买价格 | 数字 | ❌ | 单位：元 |
| 购买平台 | 选择 | ❌ | 京东 / 淘宝 / 拼多多 / 实体店 / 其他 |
| 店铺名称 | 文本 | ❌ | 如 Apple Store 官方旗舰店 |
| 存放位置 | 文本 | ❌ | 如 卧室衣柜 |
| 数量 | 数字 | ❌ | 默认 1 |
| 状态 | 选择 | ❌ | 使用中 / 闲置中 / 已损坏 / 已出售 / 已送人 / 收藏中 |
| 备注 | 多行文本 | ❌ | 补充说明 |

**图片管理**（v3 新增）：

- 支持添加多张图片（从相册选择，多选）
- 图片存储在 `documentDirectory/images/`，以 UUID 命名
- JSON 中仅存储文件路径，不内嵌 base64
- 列表卡片显示首张缩略图（若有）
- 详情页水平滚动图片画廊，点击放大全屏查看
- 编辑时支持增量操作：新增图片复制到持久化目录，删除图片同时清理文件

**自定义字段值**（v3 新增）：

- 根据所选分类的自定义字段配置，动态渲染额外的输入项
- 支持类型：文本 → TextInput，数字 → TextInput（数字键盘），日期 → DatePickerModal
- 切换分类时，自定义字段值自动清空

**匣中列表**：

- 按时间排序（创建时间倒序）
- 按分类分组（SectionList）
- 双视图一键切换
- 下拉刷新
- 入匣菜单入口（截图识别 / 文件导入）
- 闲置提醒徽章：右上角铃铛图标 + 红色数字角标

**匣物详情**：

- 图片画廊（横向滚动，点击全屏）
- 完整字段展示
- 自定义字段值的专门展示区域
- 底部「改匣」按钮
- 标题栏右侧移出按钮（确认弹窗后移出物匣，同时清理关联图片）
- 匣灵评价展示区

### 7.2 分类管理模块

**功能描述**：自由创建和管理匣物分类，支持自定义字段配置。

**基础功能**：

- 新增分类（名称 + emoji 图标 + 颜色）
- 编辑分类（修改名称 / 图标 / 颜色 / 自定义字段）
- 删除分类（清空该分类下匣物的关联，不删除匣物本身）
- 长按分类卡片进入编辑
- 点击分类卡片进入该分类下匣中列表

**预设图标**（12 个）：

📦 📫 👔 👗 💍 🎮 🏃 🎧 💪 🌪 🎵 📡

**预设颜色**（7 色）：

靛蓝 `#4F46E5` · 翠绿 `#059669` · 琥珀 `#D97706` · 红色 `#DC2626` · 紫色 `#7C3AED` · 青色 `#0891B2` · 粉红 `#BE185D`

**自定义字段配置**（v3 新增）：

- 每个分类可添加多个自定义字段
- 字段类型：文本（text）/ 数字（number）/ 日期（date）
- 字段存储于 Category.customFields[]，在入匣/改匣时动态渲染
- 支持增删自定义字段

### 7.3 搜索筛选模块

**搜索条件**：

- 关键词寻觅（名称 / 品牌 / 备注模糊匹配）
- 分类筛选（下拉选择）
- 状态筛选（下拉选择）
- 三项条件可同时组合

**结果展示**：

- 按创建时间倒序排列
- 最多显示 50 条
- 点击结果进入匣物详情

**匣灵入口**：

- 搜索页面入口按钮「匣灵」，点击进入匣灵问答页

### 7.4 匣灵问答模块（v3 新增）

**功能描述**：基于匣主物匣数据作为上下文，调用 LLM 进行自然语言查询和统计分析。

**交互方式**：

- 聊天式 UI：匣主输入问题 → 匣灵返回回答
- 快捷提问按钮（6 个预设）：
  - 📊 物匣概览
  - 💤 有哪些闲置匣物
  - 💰 哪个平台花最多
  - 🆕 最近买了什么
  - 💎 最贵的是哪些
  - 🏪 京东买了什么
- 支持清空对话历史

**上下文注入策略**：

- 每次提问时将全量物匣数据（匣中列表 + 统计信息）压缩后作为 system 消息注入
- 单次对话最大 token：1500
- 温度：0.3（偏确定性）

**AI 配置**（与 OCR 共享）：

- 供应商选择：OpenAI / DeepSeek / 自定义
- API Key（安全存储，密码框输入）
- API Base URL
- 模型名称（默认 gpt-4o / deepseek-chat）
- 添加后 AI 评价开关
- 配置持久化到 `warehouse-ocr-settings.json`

### 7.5 数据导入模块（v3 新增）

#### 7.5.1 OCR 截图识别

**功能描述**：上传电商订单截图，AI 视觉模型自动提取购买信息。

**操作流程**：

1. 从相册选择订单截图
2. 图片预览
3. 点击"开始识别"
4. AI 返回识别结果（名称 / 品牌 / 价格 / 平台 / 店铺 / 日期 / 数量）
5. 支持编辑模式：可直接修改识别结果
6. 确认后收入物匣

**识别字段**：

| 字段 | 类型 | 说明 |
|------|------|------|
| name | 文本 | 商品名称 |
| brand | 文本 | 品牌（无法识别则为空） |
| purchasePrice | 数字 | 价格（元） |
| purchasePlatform | 选择 | 淘宝/天猫/京东/拼多多/抖音/其他 |
| storeName | 文本 | 店铺名称 |
| purchaseDate | 日期 | YYYY-MM-DD |
| quantity | 数字 | 默认 1 |

**技术细节**：

- 使用与匣灵问答相同的 API 配置
- 图片以 base64 + data URI 发送给模型
- 模型返回 JSON，前端用正则提取并解析
- 默认模型：gpt-4o（视觉能力）

#### 7.5.2 CSV / Excel 批量导入

**功能描述**：从购物平台导出的订单文件中批量解析匣物信息。

**支持格式**：`.csv`、`.xlsx`、`.xls`

**列名自动映射**：

| 目标字段 | 识别的列名（不区分大小写） |
|----------|--------------------------|
| name | 商品名称 / 商品 / 产品名称 / 宝贝名称 / 商品标题 / 名称 / product name / name / title / item / product |
| brand | 品牌 / 品牌名称 / brand |
| purchasePrice | 实付款 / 实付金额 / 成交价 / 单价 / 价格 / 商品单价 / 金额 / 应付金额 / 支付金额 / price / amount / total |
| purchasePlatform | 平台 / 购买平台 / 来源 / platform / source |
| storeName | 店铺名称 / 店铺 / 卖家 / 商家 / shop / store / seller |
| purchaseDate | 下单时间 / 购买时间 / 成交时间 / 支付时间 / 订单创建时间 / 创建时间 / 时间 / 日期 / date / time / order date |
| quantity | 数量 / 购买数量 / 件数 / quantity / qty / count |

**操作流程**：

1. 选择文件
2. 自动解析，显示识别到的记录列表
3. 每条记录显示：名称、价格、平台、日期
4. 支持全选 / 单选 / 取消选择
5. 点击「导入选中」批量入匣

**平台推断**：

- 若文件中无平台列，根据文件内容关键词推断（京东 / 淘宝 / 拼多多 / 抖音）

### 7.6 物匣统计模块（v3 新增）

**功能描述**：多维度可视化分析匣中数据。

**统计维度**：

| 图表 | 类型 | 说明 |
|------|------|------|
| 月度消费趋势 | 柱状图 | 按月汇总购买金额，近 12 个月 |
| 分类分布 | 横向柱状图 | 各类别匣物数量 + emoji 图标 |
| 购买平台分布 | 横向柱状图 | 各平台购买数量 |
| 匣物状态分布 | 横向柱状图 | 各状态匣物数量 + 颜色编码 |

**入口**：匣主 → 查看物匣统计

### 7.7 闲置提醒模块（v3 新增）

**功能描述**：自动检测长期未更新的闲置匣物并提醒匣主处理。

**提醒逻辑**：

- 仅检测状态为「闲置中」的匣物
- 判断条件：`当前时间 - updatedAt > 阈值天数`
- 按闲置时长升序排列（闲置最久的排最前）

**提醒设置**：

- 可配置阈值：7 天 / 14 天 / 30 天 / 60 天 / 90 天（默认 30 天）
- 设置存储于 localStorage

**UI 表现**：

- 匣中列表右上角铃铛图标 + 红色角标数字（超过阈值的闲置匣物数）
- 列表顶部 IdleReminderBanner 横幅
- 点击进入闲置匣物独立列表页

### 7.8 匣主模块

**匣主资料**：

- 匣主之名编辑
- 头像：点击头像进入编辑页，首字或「匣」占位符（未设头像时）

**匣主等级**（v3 新增）：

6 级成长体系，基于匣中件数自动升级：

| 等级 | 名称 | 图标 | 所需匣中件数 |
|------|------|------|-------------|
| Lv.1 | 初启匣主 | 📦 | 0 |
| Lv.2 | 拾物匣主 | 🔰 | 10 |
| Lv.3 | 积物匣主 | 📚 | 30 |
| Lv.4 | 理匣师 | 🎯 | 60 |
| Lv.5 | 丰匣主人 | 👑 | 100 |
| Lv.6 | 万物匣主 | 🌟 | 200 |

- 匣主页显示当前等级图标 + 名称 + 进度条
- 进度条显示当前进度（如 25/30 → 下一级：积物匣主）
- 到达最高级显示 "MAX"
- 点击等级卡片查看完整匣主等级弹窗

**数据概览**（StatsRow）：

- 匣中件数
- 闲置匣物数（可点击进入闲置列表）
- 总价值（¥）
- 匣主等级进度

**云盘同步**：

- 同步文件夹路径配置（手动输入完整路径）
- 自动同步开关 + 频率选择：
  - 每次修改后（every_change）
  - 每 5 分钟（every_5min）
  - 每 30 分钟（every_30min）
- 手动导出 / 导入 JSON
- 导入前检查远程文件是否较新，确认后合并
- 同步状态显示：已同步 / 云端有更新
- 同步策略：按记录级 updatedAt 时间戳对比，取较新版本

**OTA 热更新**（v3 新增）：

- 基于 expo-updates
- 启动时 + 从后台回到前台时自动检查更新
- 发现新版本自动后台下载
- 下载完成后顶部显示绿色横幅"新版本已就绪 · 立即重启"
- 状态栏显示三种状态：检查中（紫色）/ 下载中（紫色 + 百分比）/ 就绪（绿色）

```bash
cd apps/mobile
```

### 9.3 多设备同步

1. 在一台设备上使用 App 打理物匣
2. 进入「匣主」→ 设置同步文件夹路径（如夸克网盘同步文件夹）
3. 开启自动同步或手动点击「导出数据」
4. 在另一台设备上设置相同同步文件夹路径
5. 云盘软件自动将文件同步到其他设备
6. 打开 App →「匣主」→ 点击「导入数据」合并数据
